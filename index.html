Preguntas frecuentes

Dudas comunes

¿Cuánto cuesta una web o un sistema?

Depende del alcance. Después de una charla te paso un presupuesto dividido en etapas.

¿Cuánto tarda?

Una landing puede estar en días; un sistema de gestión se arma por módulos y vas usando las primeras partes mientras se construye el resto.

¿Trabajás fuera de Córdoba?

Sí. Todo el proceso se puede hacer a distancia, con videollamadas y prototipos que probás desde tu celu.

¿Puedo empezar con algo chico?

Sí. Se puede arrancar por una parte, por ejemplo pedidos o stock, y sumar módulos después.

¿Qué pasa después de entregarlo?

Sigo disponible para soporte, ajustes y mejoras.
